# Escovando-Bits-em-C

A maioria dos tutoriais ensina a programar apertando o botão "Play" em uma interface gráfica. Este repositório é diferente. Aqui, o objetivo não é apenas aprender a sintaxe da linguagem C, mas entender como os sistemas operacionais, a memória e as redes funcionam por baixo dos panos.

Sem mouses, sem abstrações que escondem o problema. Apenas Linux, Vim, GCC e manipulação manual de memória.

### A Filosofia: O Fim das Caixas Pretas
Na área de T.I. e infraestrutura, lidamos diariamente com servidores, intranets e sistemas de rede complexos. O problema é que a maioria dos profissionais acaba tratando essas ferramentas como "caixas pretas": se funciona, ótimo; se o serviço cai ou trava, ninguém sabe o real motivo. 

Aprender C não é sobre virar um desenvolvedor de software tradicional. É sobre desmontar essa caixa preta. É entender como a máquina gerencia conexões, como a memória de um servidor é alocada de verdade e como ferramentas de rede, firewalls e sistemas operacionais operam na raiz. Quem domina o baixo nível, não fica refém da máquina.

### O Método: Laboratório Aberto
Este espaço funciona como um laboratório pessoal no formato "Learn in Public" (Aprendendo em Público). 

Não espere tutoriais polidos e higienizados. Espere encontrar logs de erro crus do GCC, telas de *Segmentation Fault*, testes de compilação destrinchados e epifanias sobre o funcionamento do sistema. É um registro real e contínuo de experimentação.
